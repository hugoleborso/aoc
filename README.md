# 🎄🌟🌟 Advent of Code 🎄🌟🌟

**Advent of Code** is an annual advent calendar of small programming puzzles that can be solved in any programming language.

Annual editions I participated in : [2025](https://adventofcode.com/2025), [2022](https://adventofcode.com/2022), [2021](https://adventofcode.com/2021)
